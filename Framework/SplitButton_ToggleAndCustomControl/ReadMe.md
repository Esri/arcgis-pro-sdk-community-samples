## SplitButton_ToggleAndCustomControl

<!-- TODO: Write a brief abstract explaining this sample -->
Hosts an editing-toolbar interface inside a ribbon split button and synchronizes its visibility with the split button's toggle command.  
  
The split button toggles the editing mini toolbar visibility and re-creates on the dropdown, UI from  the Editing backstage options controlling the mini toolbar options.

## How to use the sample
<!-- TODO: Explain how this sample can be used. To use images in this section, create the image file in your sample project's screenshots folder. Use relative url to link to this image using this syntax: ![My sample Image](FacePage/SampleImage.png) -->
1. In Visual Studio click the Build menu. Then select Build Solution.
2. Click Start button to debug ArcGIS Pro.  
3. Open any ArcGIS Pro project. Navigate to the Add-In tab on the ribbon.   
4. Click the dropdown part of the Editing Toolbar button.  This will display the custom control showing the mini toolbar options.   
![UI](Screenshots/Screenshot1.png)  
5. Turn the mini toolbar on by clicking the checkbox in the upper right of the dropdown.   
6. Open the Create Features dockpane and activate a line or  polygon template to initiate an editing action.The editing toolbar should be displayed.  
7. Modify the radio buttons and checkbox on the dropdown UI of the split button and verify that the  editing toolbar changes position and size accordingly.
